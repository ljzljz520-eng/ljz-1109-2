设计规范说明

壹设计原则：器物气质的数字化转译

  • 丝釉关系：景泰蓝的视觉本质是“金线勾边、釉料填格”。界面用 --color-wire 金色细线（--wire token）对应铜丝，用浓郁色块对应珐琅釉，卡片边框即“掐丝”。
  • 绢纸为底：宣纸底色 --color-paper 叠加极淡噪点纹理，模拟绢本；低性能模式自动移除纹理与背景附着。
  • 釉色克制：珐琅五色（蓝、红、松石绿、雄黄、牙白）只用于强调与数据色，大面积正文保持墨色 --color-ink，避免色彩喧闹。
  • 宋式秩序：标题取宋体（Noto Serif SC）、宽行距 1.85、区块居中对称，呼应官窑构图的端庄；交互控件用无衬线保证清晰度。
  • 真实可验：本规范的每个组件都可在站点实际页面找到对应实例，而非纯文档示意。

贰主题 Token

所有设计取值集中定义于 assets/css/tokens.css 的 :root，组件样式只允许引用变量、不得硬编码色值与尺寸。Token 分七层：品牌釉色、语义别名、字体、间距、圆角阴影、动效、布局。

/* tokens.css 节选 */
:root {
  /* 釉色 → 语义别名 */
  --color-primary: var(--color-enamel-blue);
  --color-accent: var(--color-enamel-red);
  --color-gold: var(--color-wire);
  --color-bg: var(--color-paper);
  --color-surface: var(--color-paper-card);

  /* 动效 */
  --dur-fast: 160ms;  --dur: 280ms;  --dur-slow: 520ms;
  --ease-out: cubic-bezier(0.22, 0.61, 0.36, 1);
}

肆字体排印

伍间距、圆角与阴影

间距遵循 4px 基准网格，页面横向留白用 --gutter 随视口弹性伸缩（clamp 16–40px）。圆角分四档，卡片用 --radius-lg: 14px；阴影仅两档（静态 / 悬停），低性能下全部置空。

柒动效与滚动显现

  • 时长 token：--dur-fast 160ms（小反馈）、--dur 280ms（悬停）、--dur-slow 520ms（滚动显现、图片淡入），统一缓动 --ease-out。
  • 悬停反馈：卡片 translateY(-8px) + 阴影加深；按钮上浮 2px；器物 SVG scale(1.07)；案例卡釉面有一次性扫光；导航下划线由中心展开。
  • 滚动显现：.reveal 元素初始透明下移 34px，进入视口 12% 时加 .is-inview；方向变体 data-reveal="left|right|zoom"；同组可用 data-delay="90" 错峰。基于 IntersectionObserver，进入后即 unobserve，只播放一次。

捌懒加载策略

  • 案例器物 SVG 容器标记 data-lazy-art="案例id"，默认渲染金色 shimmer 骨架屏（.art-skeleton）。
  • IntersectionObserver 以 rootMargin: 160px 预读：卡片距视口 160px 时即由 svg.js 生成内联 SVG，先插入再加 .is-loaded 透明淡入，骨架屏移除。
  • 数据与结构同源：列表卡、详情大图共用 CASES 数据与 vesselSVG()，保证“所见即同一器物”。
  • 字体使用 display=swap，避免字体阻塞渲染。
// app.js · lazyArt() 节选
// 低性能或不支持 IO：跳过观察与骨架，直接同步渲染
if (Perf.isLow() || !('IntersectionObserver' in window)) render();
else io.observe(slot);  // rootMargin: 160px 预读

玖低性能模式降级

三种触发方式，优先级从高到低：URL 参数 ?perf=low / ?perf=high → 用户选择（localStorage 持久化）→ 自动探测（hardwareConcurrency ≤ 2、deviceMemory ≤ 2 或开启省流 saveData）。也响应系统 prefers-reduced-motion。

能力标准模式低性能 / 减弱动效

懒加载骨架屏 + 160px 预读 + 淡入同步渲染全部 SVG，无骨架无动画
悬停反馈上浮/扫光/缩放保留颜色反馈，去除位移与扫光
背景与模糊绢纸噪点、毛玻璃页眉、头图底纹全部移除

拾壹无障碍与包容性

  • 语义标签：header/nav/main/article/section/figure，导航有 aria-label，当前页用 aria-current="page"。
  • 筛选 chip 用 aria-pressed，折叠面板用原生 details/summary，toast 用 role="status" aria-live="polite"。
  • 所有装饰 SVG 标 aria-hidden，器物 SVG 带描述性 aria-label（如“掐丝珐琅缠枝莲纹梅瓶纹样示意”）。
  • 键盘可达：焦点态统一金色 --ring 外环；汉堡按钮 aria-expanded / aria-controls。
  • 色彩对比：正文墨色对宣纸底对比度 > 10:1；状态不仅依赖颜色（选中 chip 同时有填充与按压属性）。
  • 减弱动效：遵循 prefers-reduced-motion，效果与低性能模式一致。
